# My dotfiles

this is a small description of my dotfiles for my setup archlinux <3

## Favorites dotfiles

- tmux: my terminal sessions
- nvim: my preferences of lsp's, plugins, etc.
- hypr: my config hyprland based totally in cattpuccin theme.

## Instructions of use

clone this project:

`git clone https://github.com/Jorgirerison/dotfiles.git` 

download stow:

`sudo pacman -Sy stow` 

inside of the directory `dotfiles` write:

`stow nvim` 

for example, and each preferred directory the patters is the same: `stow tmux,hypr,ect...`
